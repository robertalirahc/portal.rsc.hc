# Portal de Apoio ao RSC

Versão preparada para publicação direta no GitHub Pages.

## Publicação

1. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
2. No GitHub, acesse **Settings > Pages**.
3. Em **Build and deployment**, selecione:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** / (root)
4. Salve e aguarde a publicação.

A estrutura correta deve manter `index.html` e a pasta `assets` no mesmo nível.
