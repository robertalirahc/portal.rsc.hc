# Portal de Apoio ao RSC - versão 2

Portal estático destinado aos servidores RJU do Hospital das Clínicas da UFPE.

Unidade responsável: Unidade de Desenvolvimento de Pessoal (UDP/DIVGP).

## Visualização
Abra `index.html` no navegador.

## Publicação no GitHub Pages
Envie toda a pasta ao repositório, acesse Settings > Pages e publique a branch principal a partir da raiz.
